## Implemented

- Retains v0.4 compressed backup parsing, hierarchy, selection regions, incremental imports and camera suppression.
- Local texture index uses SHA256 filenames or parent directory hashes and model-scoped manifest relationships. Replacements verify source bytes. No global filename-only guesses.
- PNG/JPEG signature detection; bounded KTX1 BC1, BC3, BC4 unsigned and BC5 unsigned decoding using Blender's bundled NumPy. BC3 was added after actual foliage headers were inspected. Normal Z reconstruction and PNG alpha preservation.
- Persistent decoded texture cache and separate colour/data Blender image datablocks.
- Visual Reconstruction panel: repair selected entities, active collection, region or all imported objects. Worker indexing/conversion, incremental relinking and cancellation. Automatic repair after area imports.
- Explicit metallic image semantics correct the previous Specular socket assignment. Explicit gloss maps invert to roughness. Existing normal links and other shader graphs are preserved. Original links/references are recorded.
- Reference camera parses hifi location strings, converts coordinates and orientation, and provides horizontal FOV, eye height and third-person distance. Creates a surrounding selection region.
- New light imports use source colour, intensity, falloff, dimensions, cone and shadow flags. Power is an approximation matched at half the source cutoff distance, not a renderer-equivalent conversion. Embedded FBX lights are disabled with their prior energy retained.

## Installation / initial use

Save your current scene and use a copy. Disable the older WorldBridge add-on before installing this ZIP through Blender Preferences > Add-ons > Install from Disk. Restart Blender if an earlier WorldBridge module remains loaded.

Import the backup as placeholders. In WorldBridge > Visual Reconstruction enter:

`hifi://example.local/10586.7,9942.49,10003.9/0,0.903835,0,-0.427881`

Start with FOV 70, eye-height offset 1.6 and third-person distance 3. These are assumptions, not measured viewer camera settings. Create Camera and Surrounding Area; use a conservative model limit and Load Surrounding Area. Configure the read-only rescue root and a writable recovery output directory. Repair Imported Scene also works on existing imported geometry. Detailed recovery results appear in Blender's Text Editor and the recovery output directory.

## Incomplete / needs verification

- Full final Blender 4.2 and 4.5 regression runs and interactive installation/UI/cancellation tests.
- Final visual acceptance of West Passage and two independent locations. No claim that the courtyard is now visually correct.
- Local model lookup exists in recovery.Index but is not wired into the import downloader. Offline cached-model loading still follows v0.4 behaviour; not all rescue models are automatically reused.
- Zone skybox/ambient translation and precise near-field/range lighting remain incomplete. Existing scene light repair is currently a Python API (`worldbridge.lighting.repair_scene`), not a panel operation.
- Material reconstruction is conservative and partial. Glass/transmission, creator-specific specular/gloss conventions and custom graphs require further tests. No substitute textures were generated.
- Final grouped unsupported/unavailable dependency inventory must be taken from the latest recovery report. KTX2 and other unimplemented formats remain explicitly unsupported.
- The original v0.4 texture helper remains as unused legacy code; the public helper routes to v0.5 recovery.
